# Leave Management Portal

A full-stack Leave Management System built with Next.js, TypeScript, and PostgreSQL.

## ?? Live Demo
**Production URL:** [https://eesha-pai-p.vercel.app/](https://eesha-pai-p.vercel.app/)

## ?? Features
- **Employee Dashboard:** Submit leave requests and view real-time status and leave balances.
- **Admin Dashboard:** Review, approve, and reject pending leave applications.
- **Modern Tech Stack:** Built with Next.js 15 (App Router), Tailwind CSS, and NeonDB (PostgreSQL).
